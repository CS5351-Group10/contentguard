## How to add yourself (first PR exercise)

1. Create a branch: `git checkout -b team/roster-<github-id>`
2. Edit this file: fill the `—` row that matches your main line (keep one row per member).
3. Commit and push the branch, then open a PR to `main`.
4. In the PR body, paste this line:
   `Test-Plan-Approved: n/a (docs-only change, no tests affected)`
5. PM reviews, approves, and merges. The PR counts toward your contribution log (~0.5 h).
